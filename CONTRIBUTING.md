# Contributing

Thank you for contributing to django-native-postgres.

Before opening a pull request:

1. Read the [AI assistance policy](AI_POLICY.md).
2. Follow the development instructions in
   [docs/development.md](docs/development.md).
3. Add or update tests for behavioral changes.
4. Run the formatting, linting, and test commands described in the development
   documentation.

Contributors remain responsible for every change they submit.
