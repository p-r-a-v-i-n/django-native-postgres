# Architecture decision records

Substantial design decisions are made together before implementation and
recorded here. Each record should contain:

- context and problem;
- constraints and correctness requirements;
- options considered;
- chosen option and rationale;
- consequences and known risks;
- validation or benchmark plan; and
- status: proposed, accepted, superseded, or rejected.

Use the next sequential filename, for example:

```text
0001-native-driver.md
0002-execution-request.md
0003-connection-affinity.md
```
